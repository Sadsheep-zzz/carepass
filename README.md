# CarePass

CarePass is a standalone, fictional demo for preparing a concise patient health profile for a clinician.

## Open the website

Visit https://sadsheep-zzz.github.io/carepass/ or open `index.html` in a browser.

## Demo accounts

- Patient: `patient@carepass.demo` / `patient123`
- Doctor: `doctor@carepass.demo` / `doctor123`

## Privacy and limits

This is a browser-only demonstration. Demo data is stored in this browser and is not sent to a CarePass server. It has no real authentication or secure patient-to-clinician authorization. Do not enter real patient information. It does not diagnose or provide medication-safety clearance.
